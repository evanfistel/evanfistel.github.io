F1 Telemetry: Where the Lap Time Goes

Using public F1 telemetry to break a qualifying lap delta down corner by corner.

ToolsPython · FastF1 · pandas · matplotlib
Timeline2026
TypePersonal project
Code / filesGitHub repo

The question

Two drivers set fastest laps within a few tenths of each other. Where exactly is that time gained and lost, and what does the telemetry suggest about how each driver approached the corners?

Approach

  • Loaded session data with the FastF1 Python library and selected each driver's fastest lap.
  • Interpolated both laps onto a common distance axis so traces line up corner by corner.
  • Computed a running time delta and split the lap into braking, cornering, and traction zones.
  • Compared braking points, minimum corner speeds, and throttle application on exit.

Limitations

Public telemetry is sampled at a low rate and doesn't include steering, tire, or fuel data, so conclusions about technique are inferences.
